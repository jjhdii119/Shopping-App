# ☕ Kopi dan Nyemil 🥐
**Ujian Tengah Semester - Pengembangan Aplikasi Mobile**

Aplikasi mobile berbasis Android untuk pemesanan kopi dan camilan secara cepat dan mudah. Aplikasi ini dibangun dengan antarmuka yang modern, estetik, dan *user-friendly*, menggunakan tema *classic cafe* yang unik.

## Fitur Aplikasi (Sesuai Kriteria UTS)
Aplikasi ini menggunakan navigasi yang mulus dan *dummy data* (tanpa database) dengan halaman berikut:
1. **Splash/Welcome Screen:** Halaman sapaan estetik dengan maskot Kucing Koki.
2. **Sign Up (Landing Page):** Gerbang utama untuk memilih masuk atau mendaftar.
3. **Login & Register:** Form input pengguna dengan validasi desain yang rapi.
4. **Home (Menu Utama):** Menampilkan daftar minuman dan makanan (14 item) menggunakan `RecyclerView`. Dilengkapi *Bottom Navigation* minimalis.
5. **Keranjang & Konfirmasi Pesanan:** Menampilkan ringkasan pesanan dan total harga.
6. **Alamat Pengiriman:** Form pengisian detail lokasi pengiriman.
7. **Order Success:** Halaman status pesanan siap diantar.
8. **Profile:** Halaman informasi akun pelanggan (customer08) dengan avatar standar bawaan Android dan tombol *Log Out*.

## Teknologi yang Digunakan
* **Bahasa Pemrograman:** Kotlin
* **IDE:** Android Studio
* **Layouting:** XML (RelativeLayout & LinearLayout)
* **Komponen Utama:** RecyclerView, Intent, Bottom Navigation (Custom)
* **Aset:** Vector Asset Android & Custom PNG/JPEG
